# Система фоновых загрузок

## Что изменилось

Система загрузок была полностью переработана для поддержки фоновых загрузок:

### 1. Глобальный контекст загрузок (`contexts/download-context.tsx`)
- Управляет очередью загрузок
- Загрузки продолжаются независимо от текущей страницы
- Автоматическое сохранение в IndexedDB

### 2. Индикатор прогресса (`components/download-progress-indicator.tsx`)
- Плавающий виджет в правом нижнем углу
- Показывает активные загрузки в реальном времени
- Раскрывается для просмотра деталей
- Возможность отмены отдельных загрузок

### 3. Упрощённый диалог выбора (`components/episode-selector-dialog-v2.tsx`)
- Выбор эпизодов, озвучки и качества
- Моментальное добавление в очередь
- Можно закрыть диалог и продолжить навигацию

### 4. Страницы
- **`/downloads`** - Карточки с группировкой по аниме
- **`/downloads/[animeId]`** - Оффлайн просмотр со встроенным плеером

## Использование

1. Откройте любое аниме и нажмите "Скачать"
2. Выберите эпизоды, озвучку и качество
3. Нажмите "Скачать" - эпизоды добавятся в очередь
4. Свободно перемещайтесь по сайту во время загрузки
5. Наблюдайте за прогрессом в правом нижнем углу
6. Когда загрузка завершится, перейдите в "Загрузки" для оффлайн просмотра

## Преимущества

✅ Свободная навигация во время скачивания  
✅ Множественные загрузки одновременно  
✅ Автоматическая повторная попытка при ошибках  
✅ Прогресс в реальном времени  
✅ Отмена отдельных загрузок  
✅ Полностью оффлайн просмотр  

## Технические детали

- **React Context API** - глобальное состояние загрузок
- **IndexedDB** - хранение видеофайлов
- **Blob URLs** - воспроизведение оффлайн видео
- **Progress tracking** - отслеживание сегментов HLS
